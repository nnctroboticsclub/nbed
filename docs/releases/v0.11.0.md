# v0.11.0

日付: 2026-11-01

対応MCUの全UART/USARTを非同期シリアルとして使用できるようにするリリースです。
F446REのUSART6を含む未実装の系統を追加し、通常送受信・受信割り込み・DMAに対応しました。
従来と同じGitHubのプレリリースとして公開します。

## 追加・修正内容

- F446REに `kUsart1`・`kUart5`・`kUsart6` を追加し、全6系統に対応しました。
- F767ZIに `kUsart1`・`kUart5`・`kUart7`・`kUart8` を追加し、全8系統に対応しました。
- 追加した系統にもクロック・割り込み・コールバック・コンソール・DMA送受信を実装しました。
  F7ではUSART1/6にPCLK2、それ以外にPCLK1を選択します。
- F7のUSART1、UART4/5/7について、ピンごとに異なるAF番号を設定します。
  RX/TXを異なるAF番号の候補から選ぶこともできます。
- F3/F4/F7で無効な周辺機能番号が、既存UARTの割り込み処理に紛れ込まないようにしました。
- [UARTガイド](https://github.com/nnctroboticsclub/nbed/blob/v0.11.0/docs/uart.md)に
  全系列のピン・AF一覧とUSART6の使用例を追加し、DMAの固定割当て表を更新しました。

## F446REのUSART6を使う

```ini
lib_deps =
    https://github.com/nnctroboticsclub/nbed.git#v0.11.0
```

```cpp
Uart serial(kUsart6, kPC7, kPC6, 115200);  // RX, TXの順
if (!serial.Initialize()) {
  System::ErrorHandler();
}
```

正式な指定名は `kUsart6` です。既定コンソールのUSART2とは別に使用できます。

| MCU | 対応するUART/USART |
| --- | --- |
| F303K8 | USART1 / USART2（全2系統） |
| F446RE | USART1 / USART2 / USART3 / UART4 / UART5 / USART6（全6系統） |
| F767ZI | USART1 / USART2 / USART3 / UART4 / UART5 / USART6 / UART7 / UART8（全8系統） |

## 互換性と制約

- 既存の `Uart` APIと列挙値の数値は維持しています。新しいUARTは末尾に追加しました。
  F303K8は既存の2系統ですべて揃っており、対応系統・ピンは変わりません。
- 非同期の8N1通信です。同期USART・ハードウェアフロー制御・通信フォーマットの変更は提供しません。
- DMAは固定ストリーム方式です。異なるUARTやchannel番号でも同じstreamは同時に使用できません。
  たとえばF7のUART5受信とUART8送信はDMA1 stream0で競合します。
- ピンはMCUパッケージと照合しています。ボードのLED・Ethernet・デバッグ端子や、ほかの周辺機能との共用を確認してください。

## 検証

- 既存の全28環境のビルドが成功しました。
- 公開対象のソースからUbuntu上で回帰テスト56件を実行し、48件が成功しました。
  任意のPlatformIO統合テスト8件はスキップしています。
- 全16系統の全RX/TX候補の組み合わせと、各系統で全256ピン値をRX/TXそれぞれで検証しました。
  GPIOのポート・ピン・AF、クロック選択、IRQの接続、通常送受信、コンソール、受信再開、
  DMA割当て・完了・エラー・競合、所有権・破棄・再初期化・全系統同時所有も確認しました。
- 配布パッケージ126ファイルが公開対象ソースと一致することを確認しました。
  そのパッケージを使った別プロジェクトでF3/F4/F7の全UARTをリンクし、追加のF4/F7構成では
  グローバル名・グローバル待機関数を無効にしました。計5構成すべてのビルドが成功しました。
  各UARTの割り込みハンドラーが実装としてリンクされることも確認しました。
- 実機への書込み、外部機器との通信、信号波形は未検証です。
