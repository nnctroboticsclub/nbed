# v0.6.1

日付: 2026-10-23

リポジトリ名とライブラリ名を `Nbed` から `nbed` に統一するパッチリリースです。
機能追加や公開 API の変更はありません。既存と同じ GitHub のプレリリースとして公開します。

## 変更内容

- GitHub の既存リポジトリを `nnctroboticsclub/nbed` にリネームし、履歴を引き継ぎました。
- `library.json` の名前と説明文を小文字に統一し、`repository` に新しい URL を追加しました。
- 開発用のローカル依存を `nbed=symlink://.` に変更しました。
- README、利用ガイド、VS Code タスク、ログとエラーメッセージの表記を更新しました。
- 過去のリリース文書と移行記録は、当時の名称・パスを残しています。

## 利用側の設定

`platformio.ini` の依存先を小文字の URL に更新してください。

```ini
lib_deps =
    https://github.com/nnctroboticsclub/nbed.git#v0.6.1
```

既存の clone の接続先は、次のように更新できます。

```sh
git remote set-url origin https://github.com/nnctroboticsclub/nbed.git
```

`#include "nbed.h"`、`nkrc::nbed`、`NBED_...` マクロに変更はありません。
対応 MCU と既存機能は v0.6.0 と同じです。

## 検証と制約

- F303K8 / F446RE / F767ZI の全15環境でビルド成功。
- 配布パッケージの109ファイルが作業ツリーと一致することを確認。
- 配布パッケージを別の F767ZI プロジェクトから読み込んでビルド成功。
  グローバル名・グローバル待機関数・既定コンソールを無効にした構成でも確認しました。
- ホスト上の回帰テスト30件を実行して成功。
  F3 / F4 の SPI テスト2件はコンパイル成功ですが、Windows のアプリ制御（4551）により実行をスキップ。
- 任意実行の PlatformIO 統合テスト8件はスキップ。
- Windows の保護設定は変更していません。実機での書込み・通信・波形試験は未実施です。
