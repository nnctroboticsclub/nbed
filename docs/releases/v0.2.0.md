# v0.2.0

Nbed v0.2.0 をリリースしました。

このバージョンでは、ピン指定方法の改善を中心に、ライセンスの追加やドキュメントの修正を行いました。

## Changes

- Arduino互換ピン名に対応
  - `kD3` や `kD13` などのデジタルピン名でピンを指定できるようになりました。
  - `kA0` や `kA1` などのアナログピン名にも対応しました。
  - 従来の `kPA5` などのSTM32ピン名も引き続き使用できます。

- ライセンスを追加
  - プロジェクトのライセンス情報を追加しました。

- ドキュメントを修正
  - READMEなどの説明を追加・修正しました。
  - 一部の表記や説明を整理しました。

## Example

```cpp
DigitalOut led(kD13);
DigitalIn button(kD2);
```

STM32のピン名を直接指定することもできます。

```cpp
DigitalOut led(kPA5);
```
