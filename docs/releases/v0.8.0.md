# v0.8.0

日付: 2026-10-24

PWM の相補出力と HAL の出力設定を追加するマイナーリリースです。
F303K8・F446RE・F767ZI に対応し、従来と同じ GitHub のプレリリースとして公開します。

## 追加した機能

- `PwmChannel` に `kCh1N`・`kCh2N`・`kCh3N` を追加し、N 出力を単独で使えるようにしました。
- `Pwm::Configuration` の `complementary_pin` で、CHx と CHxN のペア出力に対応しました。
  比較レジスタを共有するため、ペアは1つのオブジェクトが管理します。
- HAL の通常/N出力の極性、アイドル状態、デッドタイム、OSSR/OSSI を設定できます。
- 開始・停止には `HAL_TIM_PWM_Start/Stop` と `HAL_TIMEx_PWMN_Start/Stop`、
  設定には `HAL_TIM_PWM_ConfigChannel` と `HAL_TIMEx_ConfigBreakDeadTime` を使います。
- 同じタイマで周波数・デッドタイム・OSSR/OSSI が異なる設定や、同じチャンネルの重複使用は拒否します。
  開始失敗時は出力と予約を解放し、使用中の別チャンネルは維持します。
- 既存の通常出力用コンストラクタと列挙値は維持しています。

| MCU | 対応する相補出力 |
| --- | --- |
| F303K8 | TIM1 CH1N/CH2N/CH3N、TIM15/16/17 CH1N |
| F446RE | TIM1 CH1N/CH2N/CH3N |
| F767ZI | TIM1 CH1N/CH2N/CH3N |

## 利用例

F303K8 の TIM15 CH1/CH1N を PA2/PA1 へ出力する例です。
PA2 は既定 USART2 コンソールの TX と共用するため、コンソールを無効にします。

```ini
lib_deps =
    https://github.com/nnctroboticsclub/nbed.git#v0.8.0
build_flags =
    -DNBED_NO_DEFAULT_SERIAL
```

```cpp
Pwm pair(kTim15, kCh1, kPA2, 20'000,
         {.complementary_pin = kPA1, .dead_time = 8});
if (!pair.Initialize() || !pair.SetDutyCycle(0.25F)) {
  System::ErrorHandler();
}
```

N 出力だけなら `Pwm output(kTim15, kCh1N, kPA1, 1'000);` と指定できます。
ピンだけで自動判定せず、N 出力のチャンネルを明示してください。

## 使う際の制約

- デューティ比・パルス幅は通常の CHx 側を基準にした比較値です。
  既定極性で25%を指定すると、N側の High 期間は約75%になり、デッドタイム分も反映されます。
- 初期化時の比較値は0です。N出力の初期レベルもその反転関係になります。
- `dead_time` は HAL の DTG 符号値（0〜255）です。ナノ秒や単純な tick 数ではなく、128以上では非線形です。
- CHx と CHxN を別々のオブジェクトで初期化することはできません。
- ブレーク入力は無効、ロックはオフ、自動出力は無効として初期化します。
  ブレーク入力の設定 API、PWM DMA、割り込み転送、センターアラインは今回含めていません。

全ピン表、HAL 設定、デッドタイムの単位とサンプルは
[PWM 出力設定ガイド](https://github.com/nnctroboticsclub/nbed/blob/v0.8.0/docs/pwm.md)にまとめています。
