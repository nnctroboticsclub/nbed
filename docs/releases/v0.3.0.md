# v0.3.0

## 変更点

- 部内共通名前空間 nkrc へ移行
- PlatformIO の開発環境とサンプルをリポジトリに統合
- clangd の補完・整形・診断設定を整理
- interface ヘッダーの直接 include に対応
- 単位系の引数名を命名規約に統一

## 互換性に関する注意
nbed::interface は nkrc::nbed::interface、
nbed::f4 は nkrc::nbed::stm32::f4、
単位系の nbed は nkrc::nbed に変更。
旧名前空間を明示しているコードは修正が必要です。
nbed.h 経由の初心者向けの短い名前は引き続き利用できます。
