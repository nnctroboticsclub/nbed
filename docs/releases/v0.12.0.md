# v0.12.0

日付: 2026-11-01

UARTのHAL基本・拡張初期化設定を `UartConfig` から指定できるようにするリリースです。
F303K8・F767ZIのRX/TX反転を含む拡張設定、全系列のRTS/CTSや通信フォーマット、
9データビット・パリティなしの通常転送・DMA・受信割り込みに対応しました。
従来と同じGitHubのプレリリースとして公開します。

## 設定できる機能

- `UartConfig::hal` でHALの `UART_InitTypeDef` の全フィールドを指定できます。
  baud rate、フレーム長、stop bits、parity、TX/RX mode、RTS/CTS、oversampling、
  F3/F7のone-bit samplingに対応します。F4のone-bit samplingには専用フィールドがあります。
- F3/F7は `advanced` で `UART_AdvFeatureInitTypeDef` の全フィールドを指定できます。
  RX/TX反転・データ反転・ピン入替・MSB first・overrun検出・RXエラー時のDMA制御・自動baud rate検出に対応します。
- 自動baud rate検出はF3のUSART1、F7のUSART1/2/3/6で使用できます。
  未対応のUARTや、7ビットフレームでの0x7F/0x55検出などの設定は拒否します。
- TX専用・RX専用では、使わない側のピンを `kNC` にできます。SWAPによる実際の信号方向も考慮します。
- CTS/RTSピンを明示して設定できます。各MCUパッケージのピンとAFを照合し、
  不正なピン・重複ピン・不足するピン・不要な制御ピンを拒否します。
- 通常送受信のタイムアウト、GPIOのプルと速度も指定できます。

## F303K8・F767ZIでRXを反転する例

```ini
lib_deps =
    https://github.com/nnctroboticsclub/nbed.git#v0.12.0
```

```cpp
UartConfig config{.peripheral = kUsart1, .rx = kPA10, .tx = kPA9};
config.advanced.AdvFeatureInit = UART_ADVFEATURE_RXINVERT_INIT;
config.advanced.RxPinLevelInvert = UART_ADVFEATURE_RXINV_ENABLE;
Uart serial(config);
if (!serial.Initialize()) { System::ErrorHandler(); }
```

既定は従来の8N1・非反転です。拡張設定にはHALの初期化フラグを付けてください。
フラグを付けずに対応フィールドだけを有効にした設定は、反映漏れを防ぐため拒否します。
F446REはHALにこの拡張設定構造体がないため、`advanced` は提供していません。

## 9ビットの転送

- `SendWords()` / `ReceiveWords()`、`SendWordsDma()` / `ReceiveWordsDma()` を追加しました。
  `uint16_t` の1要素が1文字で、送信値は0〜0x1FF、1回の転送は1〜65535文字です。
- `SetRxWordCallback()` と既存の `EnableRxInterrupt()` で9ビットの1文字受信に対応します。
- 9データビット・パリティなしではバイトAPIを拒否します。
  HALが16ビットで書き込む受信バッファと、halfword幅のDMAを使用します。
- `9B + EVEN/ODD` は8データビット＋パリティなので、従来のバイトAPIを使います。
  F7のDMAキャッシュ条件はバッファのバイト数で適用します。

## 互換性と対応範囲

既存コンストラクタとバイトAPIの既定動作は維持しています。
独自の `interface::Uart` 実装はそのままコンパイルでき、追加のword転送メソッドは既定で `false` を返します。

HALの通常UART初期化と拡張初期化の設定を公開しています。
同期USART、半二重single wire、LIN、RS485の自動DE、multiprocessor/mute、Stop復帰、
Receive-to-IDLE、循環DMA、Smartcard/IrDAは専用APIとしては未対応です。
詳細な対応表・RTS/CTSピン表・設定例は [UARTガイド](https://github.com/nnctroboticsclub/nbed/blob/v0.12.0/docs/uart.md)にあります。

## 検証

- 既存の全28環境のビルドが成功しました。
- 公開対象のソースからUbuntu上で回帰テスト56件を実行し、48件が成功しました。
  任意のPlatformIO統合テスト8件はスキップしています。
- 全16系統で通信フォーマットの組み合わせ、TX/RX専用、RTS/CTSの全256ピン値、
  GPIOのAF・プル・速度、HAL設定値、タイムアウト、不正な設定の拒否を確認しました。
  F3/F7の拡張設定と自動baud rate検出の対応系統、SWAP時の片方向ピンも確認しています。
- 9ビットの値・アラインメント、文字数とバイト数、halfword DMA、完了処理、
  F7キャッシュ操作、wordコールバックで9ビット値が欠けないことを確認しました。
- 配布パッケージ128ファイルの内容を公開対象ソースと照合しました。
  別プロジェクトからF3/F4/F7と、グローバル名・グローバル待機関数を無効にしたF4/F7の計5構成をビルドし、
  反転・RTS/CTS・通信フォーマット・9ビット転送のHAL連携をリンクできることを確認しました。
- 実機への書込み、反転した信号・フロー制御・自動baud rate検出の波形、外部機器との通信は未検証です。
