# v0.5.0

日付: 2026-10-23

STM32F446RE / STM32F303K8 向けの SPI を追加するマイナーリリースです。

## 変更内容

- F446RE の SPI1 / SPI2 / SPI3、F303K8 の SPI1 に対応しました。
- 8 bit・全二重の SPI マスターとして `Send()`、`Receive()`、`Transfer()` を追加しました。
  受信時は `0xff` を送信してクロックを生成します。
- モード0〜3、MSB/LSB順、ミリ秒単位のタイムアウトを指定できます。
- 通信速度は指定値を超えない最速の分周設定を選び、`GetFrequencyHz()` で実速度を取得できます。
- ピン・設定値・バッファ長を検証し、同じ SPI の二重初期化や送受信バッファの部分的な重なりを拒否します。
- 共通インターフェースと F3/F4 の実装を `nbed.h` から利用できます。
- [SPI ガイド](https://github.com/nnctroboticsclub/Nbed/blob/v0.5.0/docs/spi.md)、
  対応ピン表、両ボードで使えるループバック用サンプルを追加しました。
- SPI の設定、分周、送受信、バッファ境界、所有権、エラー処理の回帰テストを追加しました。

## 使い方と制約

既存の公開 API と名前空間は維持しています。CS は `DigitalOut` で別途制御します。
1 回の呼び出しは1〜65535 byteで、通信はブロッキングです。
DMA・割り込み転送、スレーブ、16 bit フレーム、ハードウェア NSS は未対応です。

F446RE の例（ピン順は SCK / MISO / MOSI）:

```cpp
Spi spi(kSpi1, kPA5, kPA6, kPA7, 1'000'000,
        SpiMode::kMode0, SpiBitOrder::kMsbFirst);
```

F303K8 の Arduino コネクタを使う場合:

```cpp
Spi spi(kSpi1, kPB3, kPB4, kPB5, 1'000'000);
```

配線、初期化、CS 操作を含むコードは
[SPI ガイド](https://github.com/nnctroboticsclub/Nbed/blob/v0.5.0/docs/spi.md)を参照してください。

## 検証

- SPI 用の2環境と既存の10環境、計12環境でビルド成功。
- ホスト上の回帰テスト28件成功。
- 既存の任意実行の PlatformIO 統合テスト8件はスキップ。
- 実機での通信・波形の確認は未実施。

ループバック用サンプルは、D11（MOSI）と D12（MISO）を接続して使用します。

```sh
pio run -e f4-spi-test
pio run -e f3-spi-test
```
