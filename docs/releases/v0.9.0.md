# v0.9.0

日付: 2026-10-26

F303K8・F446RE・F767ZI に外部割り込み入力を追加するプレリリースです。

## 追加した機能

- `InterruptIn` を追加し、`InterruptEdge::kRising` / `kFalling` / `kBoth` に対応しました。
- `Read()` で現在の入力値、`GetEdgeCount()` で ISR が処理したイベントの累計を取得できます。
- `SetCallback()` で任意のコールバックを登録できます。未登録でも累計は更新します。
- EXTI0〜15 の所有権を管理し、PA0/PB0 のような同番号の重複を拒否します。
- EXTI5〜9 / 10〜15 の共有 IRQ、同時保留、優先度の一致を管理します。
- `Stop()`・破棄で対象ラインを解放し、共有 IRQ のほかの入力を維持します。
  再開時は累計をリセットします。設定変更時は元の割り込み許可状態へ戻します。
- F3 の EXTI2/TSC を含むハンドラーを用意し、3系列で共通の実装を使います。
- [EXTI ガイド](https://github.com/nnctroboticsclub/nbed/blob/v0.9.0/docs/exti.md)に
  SW-420 の5入力割当て、既存アプリからの移行方法、イベント検出の制約をまとめました。
- `f3-exti-test` / `f4-exti-test` / `f7-exti-test` を追加しました。

## 利用例

```ini
lib_deps =
    https://github.com/nnctroboticsclub/nbed.git#v0.9.0
```

```cpp
InterruptIn sensor(kPA0, InterruptEdge::kBoth, GpioPull::kUp);
if (!sensor.Initialize()) {
  System::ErrorHandler();
}
const uint32_t events = sensor.GetEdgeCount();
const bool high = sensor.Read();
```

コールバックは割り込み内で実行するため、短いフラグ・カウンター更新に留めてください。
デバウンス・振動の重複排除・ゲームへの通知はアプリ側で行います。
同じラインの複数エッジが割り込み処理前に発生すると1イベントにまとまるため、
厳密な高速パルス計数や幅計測にはタイマを使用してください。
