# v0.4.0

日付: 2026-10-23

STM32F303K8 対応と、既存コードの最適化・不具合修正を含むマイナーリリースです。

## 変更内容

- NUCLEO-F303K8 向けに GPIO、ADC1/ADC2、PWM、I²C、USART1/USART2、
  Classic CAN、エンコーダ、時間待ち・計時を追加しました。
- F303K8 用の HAL 設定、ビルド環境、LED 点滅・全機能確認サンプル、
  [設定・ピン表](https://github.com/nnctroboticsclub/Nbed/blob/v0.4.0/docs/f303k8.md)を追加しました。
  既定のシステムクロックは内部 HSI による 64 MHz です。
- MCU ごとに実装とリンカスクリプトを選び、F303K8 は `-Os`、F446RE は従来の `-O3` を使用します。
- GPIO のポート・ピン変換と、同じ ADC チャンネルの再設定を省略しました。
- `printf` の出力を UART にまとめて渡し、HAL の長さ上限を超える場合だけ分割します。
- システム初期化の重複と、F3/F4 の PWM 計算を整理しました。
- 32 bit PWM の丸め、HAL ミリ秒カウンタの周回、整数版の待機時間のオーバーフローを修正しました。
- 不正な周辺機能番号、割り込み優先度、CAN 速度、HSE 周波数の検証を強化しました。
- ビルド設定とドライバロジックの回帰テストを追加しました。

## 互換性

既存の F4 公開 API と名前空間は維持しています。F3 の名前空間は
`nkrc::nbed::stm32::f3` です。`nbed.h` 経由の短い名前も使用できます。
不正な設定は初期化時に拒否されます。外部クロックを使う場合、設定の
`hse_frequency_hz` はビルド時の `HSE_VALUE` と一致する必要があります。
依存ライブラリ `logger` は引き続き v0.3.0 を使用します。

## 検証

- F4 の既存8環境と F3 の2環境、計10環境でビルド成功。
- 別の利用プロジェクトから F3/F4 のビルド成功。
- 回帰テスト26件成功。既存の任意実行の PlatformIO 統合テスト8件はスキップ。
- 実機での書込み・波形・外部通信の確認は未実施。

詳細は [最適化と検証の記録](https://github.com/nnctroboticsclub/Nbed/blob/v0.4.0/docs/optimization.md)を参照してください。

## 利用開始

このリポジトリの F303K8 用 LED 点滅サンプルは、次のコマンドでビルドできます。

```sh
pio run -e f3-blink
```
