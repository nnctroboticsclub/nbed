# v0.3.1

日付: 2026-10-18

VS Code と PlatformIO を使う開発環境を整備したパッチリリースです。

## 変更内容

- VS Code の共有設定を整理。自動保存、ファイルに応じたインデントの検出、
  編集・整形・検索・ツールの設定を統一しました。
- 推奨拡張を見直し、不要な拡張パックの推奨を削除しました。
- ビルド・書き込み・コンパイル DB の更新・通常クリーンのタスクを
  `platformio.ini` の `default_envs` に合わせました。
- 生成物・キャッシュの全削除と、削除後に既定環境をビルドする完全再ビルドを追加しました。
  削除対象はプロジェクト直下の `build/`、`.cache/`、旧 `.pio/build/` と生成 DB に限定し、
  プロジェクト外への参照がないことを確認してから削除します。
- タスクから PlatformIO 拡張の Core を直接実行するようにし、システムの PATH への依存を解消しました。
- `scripts/compiledb.py` と `extra_script.py` で、PlatformIO/SCons が実行時に提供する
  インポートや変数への Pylance 警告を必要な行だけ抑制しました。
- 開発ガイドに、タスクの使い方と PlatformIO 固有コードの静的解析について追記しました。

## 互換性

v0.3.0 から公開 API、名前空間、ライブラリの実行時の動作に変更はなく、
利用側のコードを修正する必要はありません。
Python スクリプトの実行処理にも変更はありません。
依存ライブラリ `logger` は引き続き v0.3.0 を使用します。

タスクは PlatformIO Core の標準インストール先を前提としています。
保存先を変更している場合は `.vscode/tasks.json` の実行ファイルのパスを調整してください。
