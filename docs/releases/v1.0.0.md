# v1.0.0

2026-11-28（日本時間）

nbed の初の正規リリースです。NUCLEO-F303K8、NUCLEO-F446RE、NUCLEO-F767ZI の
周辺機能とピン割り当てを照合し、未実装だった系統を追加しました。
公開 API の日本語 Doxygen コメントと、ボード別の配線ガイドを整備しました。

## 周辺機能の追加と修正

| 対象 | 変更内容 |
| --- | --- |
| F303K8 | TIM1 CH3N の PF0 を追加 |
| F446RE | FMPI2C1 と ADC2／ADC3 の明示選択を追加。I²C1 の SCL と SDA を個別に選択可能にし、SPI3 MOSI の PC1 を AF5 に修正 |
| F767ZI | SPI4～6、I²C4、CAN3、ADC2 と残りの ADC3 外部入力を追加 |
| F446RE・F767ZI | PWM に TIM4／5／8～14、エンコーダーと PWM DMA に TIM4／5／8 を追加 |

- CAN で別バンクにフィルターを設定したときに、初期の全受信フィルターを解除するようにしました。
  停止時には、そのオブジェクトが設定した受信フィルターを解放します。
- 一部の周期設定で PWM 出力がデューティ比 100% に達しなかった問題を修正しました。
- ピン判定と AF の設定を共通の対応表に揃え、ST の公式データとの比較を再実行できるようにしました。
  [ボード別の周辺機能と対応ピン](https://github.com/nnctroboticsclub/nbed/blob/v1.0.0/docs/pinout.md)

## 使い方と互換性

PlatformIO では、アプリケーションの依存ライブラリを次のタグに固定できます。

```ini
lib_deps =
  https://github.com/nnctroboticsclub/nbed.git#v1.0.0
```

`AnalogIn(pin)` は従来どおりピンから ADC を選びます。F446RE と F767ZI では
`AnalogIn input(kAdc2, kPA0);` のように使用する ADC を指定できます。
F767ZI の CAN3 は `Can bus(kCan3, kPA8, kPB4);` で作成できます。

F446RE の LQFP64 には SPI4 の信号ピンが引き出されていません。
F767ZI の低電力タイマ LPTIM1 は今回の実装範囲外です。
ボード設定と最初のサンプルは [README](https://github.com/nnctroboticsclub/nbed/blob/v1.0.0/README.md)、
API の引数・戻り値・割り込み時の使い方は [日本語 API リファレンスの生成手順](https://github.com/nnctroboticsclub/nbed/blob/v1.0.0/docs/api.md)を参照してください。

## 検証

- ST の公式ピンデータと 3 機種の 513 件の信号・ピン・AF／ADC チャンネルを照合しました。
- PlatformIO の全 28 環境をビルドしました。配布パッケージを別プロジェクトから利用する 5 構成でもビルドが成功しました。
- ホスト回帰テストと PlatformIO 統合テストの計 58 件が成功しました。F446RE の USART6 と CAN1 の PA11 RX／PB9 TX の組み合わせも確認しました。
- 日本語 Doxygen リファレンスを 3 機種の設定で警告なく生成しました。
- 実機への書き込み、外部機器との通信、信号波形の測定は未実施です。
