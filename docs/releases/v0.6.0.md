# v0.6.0

日付: 2026-10-23

STM32F767ZI / NUCLEO-F767ZI 対応を追加するマイナーリリースです。
F7 の実機確認が未実施のため、既存と同じ GitHub のプレリリースとして公開します。

## 変更内容

- F7 専用の HAL 設定と `nkrc::nbed::stm32::f7` の実装を追加しました。
  `nbed.h` 経由の短い名前も使用できます。
- GPIO、ADC1/ADC3、PWM（TIM1/2/3）、I²C1/2/3、SPI1/2/3、USART2/3/6・UART4、
  Classic CAN1/2、エンコーダ（TIM1/2/3）、時間待ち・計時に対応しました。
- 既定クロックは HSE bypass 8 MHz から216 MHz。OverDrive、Voltage Scale 1、
  Flash 7 wait states、APB1=54 MHz / APB2=108 MHz を設定します。
- 命令キャッシュを有効にし、計時用の Cortex-M7 DWT をアンロックします。
  データキャッシュを自動で有効化する処理と DMA 転送は含みません。
- F7 の I²C は HSI 16 MHz の専用タイミング計算を使用します。
- Flash 2 MiB、通常のデータ・heap・stack を SRAM1/2 の384 KiBに配置する専用リンカを使用します。
  DTCM/ITCM は既定配置では使用しません。
- F767ZI の Arduino ピン名と、既定の USART3 コンソール（RX=PD9 / TX=PD8）を追加しました。
- LED 点滅・総合確認・SPI ループバックの3環境、
  [F767ZI ガイド](https://github.com/nnctroboticsclub/Nbed/blob/v0.6.0/docs/f767zi.md)、
  クロック・I²C・ADC・UART・SPI・GPIO・計時の回帰テストを追加しました。

## 互換性と制約

F303K8 / F446RE の既存 API と名前空間は維持しています。
F7 対応は STM32F767ZI（LQFP144）が対象です。USB、Ethernet、全周辺機能の対応を意味しません。
対応する周辺機能・ピンは F767ZI ガイドを参照してください。

通常転送はブロッキングです。PWM の `SendDataDma()` は予約 API のままで、出力しません。

## 検証

- 既存12環境と F7 の3環境、計15環境でビルド成功。
- 別の F7 利用プロジェクトでも、グローバル名・グローバル待機関数・既定コンソールを無効にした構成でビルド成功。
- ホスト上の回帰テスト32項目のうち31件を実行して成功。
  F7 共通ドライバの最終再確認1件はコンパイル成功ですが、Windows のアプリ制御（4551）により実行はスキップ。
- 既存の任意実行の PlatformIO 統合テスト8件はスキップ。
- 実機での書込み、外部通信、信号波形、受信負荷試験は未実施。

```sh
pio run -e f7-blink
pio run -e f7-all-test
pio run -e f7-spi-test
```

SPI ループバックは PB5（Zio D22 / Morpho）と D12（PA6）を接続します。
既定の D11（PA7）は Ethernet PHY と共用のため、このサンプルでは使用しません。
