# v0.7.0

日付: 2026-10-23

STM32F303K8 の TIM15・TIM16・TIM17 に PWM 出力を追加するマイナーリリースです。
実機での波形確認は未実施のため、従来と同じ GitHub のプレリリースとして公開します。

## 追加した機能

- F3 の `PwmTimer` に `kTim15`・`kTim16`・`kTim17` を追加しました。
- 16 bit の周期・パルス幅・デューティ比・周波数変更に対応しました。
- TIM15/16/17 の APB2 クロックとプリスケーラによる2倍動作を反映します。
- TIM15 の2チャンネルは周波数を共有し、TIM16/17 は各1チャンネルとして管理します。
  同一チャンネルの重複使用や、存在しないチャンネル・パッケージ外のピンは拒否します。
- 既存のタイマ列挙値と API、F4/F7 の実装は維持しています。

| タイマ | CH1 | CH2 |
| --- | --- | --- |
| TIM15 | PA2（AF9） | PA3（AF9） |
| TIM16 | PA6 / PA12 / PB4（AF1） | — |
| TIM17 | PA7（AF1）/ PB5（AF10） | — |

ピンと機能は [ST DS9866](https://www.st.com/resource/en/datasheet/stm32f303k8.pdf) の
LQFP32 パッケージ・AF 表に基づきます。PB8/PB9 は F303K8 にはありません。

## 利用例とサンプル

```ini
lib_deps =
    https://github.com/nnctroboticsclub/nbed.git#v0.7.0
build_flags =
    -DNBED_NO_DEFAULT_SERIAL
```

```cpp
Pwm output(kTim15, kCh1, kPA2, 1'000);
if (!output.Initialize() || !output.SetDutyCycle(0.5F)) {
  System::ErrorHandler();
}
```

PA2 は既定 USART2 コンソールの TX と共用です。TIM15 CH1 に使う際は上記のフラグを設定し、
PA2 を使う UART を初期化しないでください。ほかの周辺機能と同じピンを併用しないでください。

波形確認用の `f3-pwm-test` を追加しました。既定コンソールを無効にし、
PA2 に 1 kHz / 25%、PA3 に 1 kHz / 75%、PB4 に 2 kHz / 50%、PB5 に 4 kHz / 50% を出力します。

```sh
pio run -e f3-pwm-test
pio run -e f3-pwm-test -t upload
```

設定・ピン・配線の詳細は [F303K8 ガイド](https://github.com/nnctroboticsclub/nbed/blob/v0.7.0/docs/f303k8.md#pwm)を参照してください。

## 検証

- F303K8 / F446RE / F767ZI の全16環境でビルド成功。
- 回帰テスト33件が成功。任意実行の PlatformIO 統合テスト8件はスキップ。
- 新しい PWM テストで、TIM15/16/17 の全ピン値・チャンネルと7通りの有効な AF 割り当てを確認。
  重複予約、周波数共有、最終チャンネルの解放、APB 分周、パルス幅・デューティ比、
  周波数変更、HAL 初期化・設定・開始の失敗後の再初期化も確認しました。
- 配布パッケージの109ファイルが作業ツリーと一致することを確認。
- 配布パッケージを別の F303K8 プロジェクトから読み込み、
  グローバル名・グローバル待機関数・既定コンソールを無効にした構成でビルド成功。
- Windows の保護設定は変更していません。実機での書込み・PWM 波形の測定は未実施です。

## 制約

TIM15/16/17 にはハードウェアのエンコーダ機能がないため、`EncoderTimer` への追加はありません。
相補出力、デッドタイム、ブレーク入力、PWM DMA、タイマの周期割り込み API は今回の対象外です。
