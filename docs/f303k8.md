# STM32F303K8 / NUCLEO-F303K8

`#include "nbed.h"` と既存の API で GPIO、ADC、PWM、I²C、SPI、UART、Classic CAN、
エンコーダ、時間待ち・計時を使用できます。対象は STM32F303K8T6（LQFP32）です。
名前空間を明示する場合は `nkrc::nbed::stm32::f3` を使います。

## 最初のビルド

このリポジトリでは次を実行します。

```sh
pio run -e f3-blink
pio run -e f3-blink -t upload
pio device monitor -e f3-blink
```

基板上の LED は `PB3` / `kD13` です。F446RE の `PA5` とは異なります。
既定のコンソールは USART2、RX=`PA15`、TX=`PA2`、921600 bps です。
Arduino の `D0` / `D1` は USART1 (`PA10` / `PA9`) で、ST-LINK の仮想 COM とは別です。

```cpp
#include "nbed.h"

int main() {
  System::Initialize();
  DigitalOut led(kD13);
  if (!led.Initialize()) {
    System::ErrorHandler();
  }
  while (true) {
    led = !led.Read();
    SleepFor(500ms);
  }
}
```

利用側のプロジェクトには次を指定します。リンカスクリプトと C++23/LTO/`-Os` は
ライブラリが設定します。Flash は 64 KB、通常 RAM は 12 KB です。追加の 4 KB CCMRAM は
通常 RAM と連続していないため、ヒープ・スタックへ加算しません。

```ini
[env:nucleo_f303k8]
platform = ststm32@20.0.0
framework = stm32cube
board = nucleo_f303k8
board_build.f_cpu = 64000000L
platform_packages =
  toolchain-gccarmnoneeabi@1.140201.0
  framework-stm32cubef3@1.11.5
board_build.stm32cube.custom_config_header = yes
lib_deps = https://github.com/nnctroboticsclub/nbed.git
```

## クロック

既定は内部 HSI の 8 MHz / 2 × 16 = **64 MHz**、APB1 は 32 MHz、APB2 は 64 MHz です。
外部発振器の追加や基板改造は不要です。HSI の周波数誤差は通信・PWM・計時にも影響します。
I²C はシステムクロックとは独立して HSI 8 MHz を使用します。

外部 8 MHz 発振器を接続した基板では、次のように 72 MHz に設定できます。
`kCrystal` と `kBypass` は実際の回路に合わせます。

```cpp
Clock::Configuration clock{};
clock.oscillator_source = Clock::OscillatorSource::kHse;
clock.hse_mode = Clock::HseMode::kCrystal;
clock.pll_multiplier = 9;
clock.hse_predivider = 1;
System::Initialize(clock);
```

`hse_frequency_hz` とビルド時の `HSE_VALUE` は一致する必要があります。F4 の
`pll_m/n/p/q` は F3 にはありません。クロックは周辺機能を初期化する前に設定してください。

## 対応ピン

GPIO は `PA0..PA15`、`PB0..PB1`、`PB3..PB7`、`PF0..PF1` を受け付けます。
`PB2` とポート C はこのパッケージに存在せず、`Initialize()` は失敗します。
`PA13` / `PA14` は SWD と、`PA15` / `PA2` は既定のコンソールと共用です。
`PF0` / `PF1` は HSE を使う場合には GPIO に使えません。
異なる周辺機能に同じ物理ピンを割り当てないようにしてください。

| 基板名 | ピン | 基板名 | ピン |
| --- | --- | --- | --- |
| D0 | PA10 | D1 | PA9 |
| D2 | PA12 | D3 | PB0 |
| D4 | PB7 | D5 | PB6 |
| D6 | PB1 | D7 | PF0 |
| D8 | PF1 | D9 | PA8 |
| D10 | PA11 | D11 | PB5 |
| D12 | PB4 | D13 / LED | PB3 |
| A0 | PA0 | A1 | PA1 |
| A2 | PA3 | A3 | PA4 |
| A4 | PA5 | A5 | PA6 |
| A6 | PA7 | A7 | PA2 |

### ADC

12 bit・単発変換です。ADC1/ADC2 は使用時に個別に初期化・校正されます。
同じ ADC の複数入力は順次読み取ります。ADC を割り込みとメイン処理から同時に呼び出す
使い方には対応していません。

| ADC | ピンとチャンネル |
| --- | --- |
| ADC1 | PA0=1、PA1=2、PA2=3、PA3=4、PB0=11、PB1=12 |
| ADC2 | PA4=1、PA5=2、PA6=3、PA7=4 |

### PWM

| タイマ | CH1 | CH2 | CH3 | CH4 |
| --- | --- | --- | --- | --- |
| TIM1 | PA8 | PA9 | PA10 | PA11 |
| TIM2 | PA0 / PA5 / PA15 | PA1 / PB3 | PA2 / PA9 | PA3 / PA10 |
| TIM3 | PA6 / PB4 | PA4 / PA7 / PB5 | PB0 | PB1 / PB7 |
| TIM15 | PA2 | PA3 | — | — |
| TIM16 | PA6 / PA12 / PB4 | — | — | — |
| TIM17 | PA7 / PB5 | — | — | — |

TIM2 は 32 bit、TIM1/TIM3/TIM15/TIM16/TIM17 は 16 bit です。同じタイマのチャンネルは周波数を共有し、
PWM とエンコーダの併用や同じチャンネルの二重使用は初期化時に拒否されます。
TIM15/16/17 は v0.7.0 から対応しています。`kTim15`、`kTim16`、`kTim17` を `Pwm` に指定します。
TIM15 は2チャンネル、TIM16/17 は各1チャンネルです。TIM15/16/17 のクロックは APB2 に接続され、
APB2 プリスケーラが1なら PCLK2、その他なら PCLK2 の2倍です。
PB5 の TIM17 は AF10、TIM16 と PA7 の TIM17 は AF1、PA2/PA3 の TIM15 は AF9 を自動設定します。
PB8/PB9 は F303K8 の LQFP32 パッケージにはないため、TIM16/17 に指定しても拒否されます。

TIM15 の PA2 は既定 USART2 コンソールの TX と共用です。PWM に使う場合は、利用側のビルド設定に
`-DNBED_NO_DEFAULT_SERIAL` を追加し、PA2 を使う UART を初期化しないでください。
PA6/PA7/PB4/PB5 は SPI1、PA12 は CAN TX とも共用するため、同じピンを併用しないでください。

```cpp
Pwm output(kTim15, kCh1, kPA2, 1'000);
if (!output.Initialize() || !output.SetDutyCycle(0.5F)) {
  System::ErrorHandler();
}
```

新しい実機確認用サンプルは、既定コンソールを無効にした `f3-pwm-test` です。

```sh
pio run -e f3-pwm-test
pio run -e f3-pwm-test -t upload
```

PA2（A7）は 1 kHz / 25%、PA3（A2）は 1 kHz / 75%、PB4（D12）は 2 kHz / 50%、
PB5（D11）は 4 kHz / 50% を出力します。波形はロジックアナライザやオシロスコープで確認してください。
TIM15/16/17 にはハードウェアのエンコーダ機能がないため、`EncoderTimer` への追加はありません。
相補出力・極性・デッドタイム・アイドル状態は、v0.8.0 から対応しています。
`kCh1N` の単独出力と CH1/CH1N のペア出力は [PWM 出力設定ガイド](pwm.md)を参照してください。
ブレーク入力・PWM DMA・タイマの周期割り込み API は未対応です。
`SendDataDma()` は F4 と同じく出力しません。

### I²C / UART / CAN

| 機能 | 入力・クロック | 出力・データ |
| --- | --- | --- |
| I2C1 | SCL: PB6 / PA15 | SDA: PB7 / PA14 |
| USART1 | RX: PA10 / PB7 | TX: PA9 / PB6 |
| USART2 | RX: PA3 / PA15 / PB4 | TX: PA2 / PA14 / PB3 |
| CAN (`kCan1`) | RX: PA11 | TX: PA12 |

それぞれの行の入力と出力は選択肢を組み合わせて使えます。I²C は 400 kHz 以下の
レジスタで表現可能な速度に対応し、指定値を超えないよう切り上げた周期を使います。
実際の通信速度には HSI の誤差とバスの立上り・立下り時間も影響します。
Fast mode（100 kHz 超）の設定は立上り 100 ns 以下・立下り 300 ns 以下を前提にしています。
バス容量に合う外付けプルアップ抵抗を用意してください。基板の SB16/SB18 が閉じていると
PB7–PA5、PB6–PA6 が接続されるため、I²C と ADC を使う際は基板の設定を確認します。

CAN は 1 系統・最大 1 Mbps、フィルタバンクは 0..13、受信は FIFO0 です。
通常通信には外部 CAN トランシーバが必要です。HSI 64 MHz の既定設定では、
1 Mbps / 500 kbps / 250 kbps / 125 kbps などを設定できます。
`NBED_NO_DEFAULT_SERIAL` を定義すると USART2 をアプリで使用できます。

### SPI

SPI1 の 8 bit マスターに対応します。モード 0〜3、MSB/LSB 順、送信・受信・同時送受信を
使用できます。CS は `DigitalOut` で別途制御します。

| 周辺機能 | SCK | MISO | MOSI |
| --- | --- | --- | --- |
| `kSpi1` | PA5 / PB3 | PA6 / PB4 | PA7 / PB5 |

Arduino D13/D12/D11 は PB3/PB4/PB5 です。PB3 は基板上 LED と共用です。
`Spi spi(kSpi1, kPB3, kPB4, kPB5, 1'000'000);` で、既定のクロックでは 1 MHz になります。
PA5/PA6 を使う場合は SB16/SB18 による PB7/PB6 との接続にも注意してください。
詳細と `f3-spi-test` の配線は [SPI ガイド](spi.md)を参照してください。

### エンコーダ

| タイマ | A相 (CH1) | B相 (CH2) |
| --- | --- | --- |
| TIM1 | PA8 | PA9 |
| TIM2 | PA0 / PA5 / PA15 | PA1 / PB3 |
| TIM3 | PA6 / PB4 | PA4 / PA7 / PB5 |

## 検証

`pio run -e f3-all-test` は SPI 以外の各機能をリンクする確認用です。実機では CAN の内部ループバック、
ADC1/ADC2 の読取り、PWM の開始・周波数変更・停止、同じタイマのエンコーダへの再割当て、
I²C 初期化、UART 受信割り込み、経過時間の表示を行います。SPI は `f3-spi-test` で確認します。
I²C の外部機器との送受信、エンコーダ入力パルス、PWM 波形の測定は別途必要です。
ADC 入力は既定で PA3 と PA4 です。信号を加えない場合の ADC 値は不定です。
ビルド確認とホスト上の回帰テストは実施しています。実機動作は未確認です。

## 外部割り込み（EXTI）

`InterruptIn` で立上り・立下り・両エッジを検出できます。GPIO の末尾番号が同じピンは
同時に使えません。共有 IRQ の優先度を揃え、基板上の周辺機器と共用するピンを避けてください。
API、制約、各ボードの試験ピンは [EXTI ガイド](exti.md)にあります。
`f3-exti-test` は PA0 の入力レベル・イベント累計・コールバック回数を表示します。
